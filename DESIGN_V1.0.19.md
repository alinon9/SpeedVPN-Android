# SpeedVPN v1.0.19 — Design Refresh

- Premium dark/glassmorphism UI with blue/cyan/purple brand accents.
- Three clear areas: Home, Speed, Settings.
- Redesigned connection hero with animated status ring.
- Live download/upload cards.
- Speed control keeps all 10 presets beside the slider.
- Compatibility controls moved into Settings instead of crowding the home screen.
- Debug information collapsed into a Diagnostics section.
- Added branded vector launcher icon (`ic_speedvpn.xml`).
- Added version label 1.0.19.
- Core VPN/network/limiter logic was not intentionally changed by the design refresh.
